# Книжкова інтернет-крамниця

Навчальний проєкт з вебтехнологій. Сайт створено на PHP та MySQL за структурою лабораторних робіт.

## Можливості

- перегляд каталогу книг;
- перегляд книг за категоріями;
- окрема сторінка книги;
- інформаційні сторінки про магазин, доставку та оплату;
- простий кошик на основі PHP-сесії;
- вхід в адмін-панель;
- додавання, редагування та видалення книг.

## Дані для входу

- логін: `admin`
- пароль: `12345`

## Запуск

1. Скопіювати проєкт у папку `htdocs`.
2. Створити базу даних через phpMyAdmin.
3. Імпортувати файл `project.sql`.
4. Перевірити налаштування підключення в `conf.php`.
5. Відкрити сайт у браузері.
